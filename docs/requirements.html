Prosper Plus Chauffeur — แพลตฟอร์มจองรถพร้อมคนขับระดับพรีเมียม

เวอร์ชัน 0.1 · ฉบับร่างรถของบริษัทB2C + B2Bเว็บไซต์รองรับทุกหน้าจอบริการระดับหรู
หลักการของผลิตภัณฑ์: ลูกค้าเลือกประเภทรถ ส่วนทีมปฏิบัติการ Prosper Plus เป็นผู้จัดรถและคนขับให้เหมาะกับงาน

1. วัตถุประสงค์

เอกสารนี้กำหนดข้อกำหนดสำหรับบริการรถพร้อมคนขับระดับพรีเมียม ลูกค้าสามารถดูบริการและประเภทรถ ส่งคำขอจอง ตรวจสอบราคา ชำระเงิน และติดตามการจอง เอกสารนี้เป็นข้อกำหนดตั้งต้นและรายละเอียดต้นแบบ ยังไม่ใช่ระบบจองหรือชำระเงินจริง

2. ขอบเขต

อยู่ในขอบเขต

  • เว็บไซต์ประชาสัมพันธ์ รายการบริการและรถ
  • ขั้นตอนส่งคำขอจอง การจองแบบไม่สมัครบัญชี และข้อมูลลูกค้า
  • ตรวจสอบราคา ส่งต่อการชำระเงิน และยืนยันรายการ
  • ติดตามการจอง บัญชีลูกค้า และประวัติ
  • สอบถามบริการองค์กร ติดต่อ คำถามที่พบบ่อย และข้อกฎหมาย
  • รองรับคอมพิวเตอร์ แท็บเล็ต และมือถือ

อยู่นอกขอบเขตระบบลูกค้ารุ่นแรก

  • ระบบจัดรถของผู้ดูแลและพอร์ทัลคนขับ
  • GPS สด สถานะรถว่างแบบเรียลไทม์ และการเชื่อมต่อระบบชำระเงิน
  • วางบิลเครดิตองค์กรและแอปมือถือ

3. ผู้ใช้งานระบบ

ผู้ใช้งานคำอธิบาย
ลูกค้าทั่วไปดูบริการและส่งคำขอจองได้โดยไม่ต้องสมัครบัญชี
ลูกค้าที่มีบัญชีจัดการข้อมูลส่วนตัวและดูรายการจองของตนเอง
ผู้ติดต่อในนามองค์กรส่งคำถามเกี่ยวกับบริการสำหรับองค์กร
ฝ่ายบริการลูกค้าให้ความช่วยเหลือลูกค้า ส่วนงานปฏิบัติการจัดการผ่านระบบผู้ดูแล
ระบบตรวจสอบข้อมูล คำนวณราคา บันทึกการจอง และแจ้งสถานะ

4. รายการบริการ

รหัสบริการรูปแบบราคาข้อมูลที่ต้องใช้
SVC-001รับส่งสนามบินราคาตามเส้นทาง / พื้นที่สนามบิน จุดรับและส่ง วันเวลา และเที่ยวบิน (ถ้ามี)
SVC-002รับส่งตามจุดหมายราคาตามเส้นทาง / ระยะทาง / พื้นที่จุดรับ จุดหมาย และวันเวลา
SVC-003รถพร้อมคนขับรายชั่วโมงรายชั่วโมงจุดรับ วันเวลา และระยะเวลา
SVC-004รถพร้อมคนขับรายวันรายวันวันเริ่มต้นและสิ้นสุด จุดรับ
SVC-005เดินทางระหว่างจังหวัดตามเส้นทาง / ระยะทาง / แพ็กเกจต้นทาง จุดหมาย วันเวลา และรายละเอียดขากลับ

บริการทุกประเภทมีคนขับ ไม่รวมบริการเช่ารถขับเอง

5. แผนผังเว็บไซต์ลูกค้า

รหัสหน้าจอหน้าจอวัตถุประสงค์ความสำคัญ
CUS-001หน้าแรกแนะนำแบรนด์ บริการ และจองอย่างรวดเร็วต้องมี
CUS-002รายการบริการเลือกดูประเภทบริการต้องมี
CUS-003รายการรถค้นหารถตามประเภทต้องมี
CUS-004รายละเอียดรถดูประเภทรถและคุณสมบัติต้องมี
CUS-005การจอง — รายละเอียดบริการระบุรายละเอียดการเดินทางต้องมี
CUS-006การจอง — เลือกรถเลือกรถที่เหมาะสมต้องมี
CUS-007การจอง — ข้อมูลลูกค้ากรอกข้อมูลผู้จองและผู้โดยสารต้องมี
CUS-008การจอง — ตรวจสอบและยืนยันตรวจสอบการจองและราคาต้องมี
CUS-009ชำระเงินชำระมัดจำหรือเต็มจำนวนต้องมี
CUS-010จองสำเร็จแสดงรหัสจองและขั้นตอนถัดไปต้องมี
CUS-011ติดตามการจองตรวจสอบสถานะการจองอย่างปลอดภัยต้องมี
CUS-012–016บัญชีลูกค้าเข้าสู่ระบบ แดชบอร์ด ประวัติ รายละเอียด และข้อมูลส่วนตัวควรมี
CUS-017สอบถามบริการองค์กรรับข้อมูลผู้สนใจใช้บริการองค์กรควรมี
CUS-018–020ติดต่อ / คำถามที่พบบ่อย / ข้อกฎหมายช่วยเหลือ เงื่อนไข และความเป็นส่วนตัวต้องมี

6. ขั้นตอนการจองหลัก

  1. เข้าเว็บไซต์และเลือกบริการ
  2. กรอกจุดรับ จุดหมาย วันเวลา จำนวนผู้โดยสารและสัมภาระ
  3. ระบบตรวจสอบว่าพื้นที่ให้บริการหรือไม่
  4. ระบบแสดงประเภทรถที่รองรับ
  5. ลูกค้าเลือกประเภทรถ
  6. ระบบคำนวณราคาในฝั่งเซิร์ฟเวอร์
  7. ลูกค้ากรอกข้อมูลติดต่อและผู้โดยสาร โดยจองได้โดยไม่ต้องสมัครบัญชี
  8. ลูกค้าตรวจสอบการเดินทาง รถ เงื่อนไข และราคา
  9. ลูกค้ายืนยันคำขอจอง
  10. ระบบสร้างรหัสจองและรายการชำระเงิน
  11. ลูกค้าชำระมัดจำหรือเต็มจำนวน
  12. ระบบอัปเดตสถานะเมื่อยืนยันการชำระเงินแล้ว และส่งข้อความยืนยัน

สำคัญ: สถานะการจองและสถานะชำระเงินเป็นคนละส่วน การเปลี่ยนหน้าเว็บกลับมาไม่ถือเป็นหลักฐานว่าชำระเงินแล้ว

7. ข้อกำหนดการทำงานของหน้าจอ

CUS-001 — หน้าแรก

ส่วนประกอบ: เมนูหลัก แบนเนอร์และปุ่มดำเนินการ แบบฟอร์มจองด่วน การ์ดบริการ รถแนะนำ ส่วนแสดงจุดเด่น ปุ่มสำหรับองค์กร และส่วนท้าย

ข้อมูลชนิดข้อมูลจำเป็นเงื่อนไข
ประเภทบริการเลือกใช่เลือกบริการที่เปิดใช้งานเท่านั้น
ประเภทรถเลือกไม่เลือกประเภทรถที่เปิดใช้งานเท่านั้น
จุดรับ / จุดหมายสถานที่ใช่อยู่ในพื้นที่ให้บริการ
วันที่ / เวลารับวันที่ / เวลาใช่เป็นไปตามเวลาจองล่วงหน้าและเวลาทำการ
จำนวนผู้โดยสารจำนวนเต็มใช่จำนวนเต็มมากกว่า 0
สัมภาระจำนวนเต็มไม่ตั้งแต่ 0 ขึ้นไป

การทำงาน: ปุ่มจองจะเลื่อนไปยังแบบฟอร์ม การเลือกการ์ดบริการจะเลือกบริการให้อัตโนมัติ และปุ่มค้นหาจะตรวจสอบข้อมูลพร้อมบันทึกเงื่อนไขค้นหา

CUS-002 — รายการบริการ

แสดงการ์ดบริการ คำอธิบาย รูปแบบราคา พื้นที่ให้บริการ และปุ่มจอง แสดงเฉพาะบริการที่เปิดใช้งาน พร้อมส่งรหัสบริการที่เลือกไปยังขั้นตอนจอง

CUS-003 — รายการรถ

ตัวกรองประเภทรถ จำนวนผู้โดยสาร สัมภาระ และคุณสมบัติ พร้อมเรียงลำดับและแสดงการ์ดรถ เผยแพร่เฉพาะประเภทรถที่เปิดใช้งาน การตรวจสอบรถว่างขึ้นอยู่กับวันและรายละเอียดการเดินทาง ต้องตรวจสอบจากระบบหลังบ้าน

CUS-004 — รายละเอียดรถ

แสดงแกลเลอรี ประเภทรถ คำอธิบาย จำนวนผู้โดยสารและสัมภาระ สิ่งอำนวยความสะดวก บริการที่รองรับ และปุ่มจอง จำนวนที่นั่งต้องอ้างอิงข้อมูลรถที่ตั้งค่าไว้

CUS-005 — การจอง: รายละเอียดบริการ

ข้อมูลชนิดข้อมูลจำเป็นการตรวจสอบ
ประเภทบริการเลือกใช่ต้องเป็นบริการที่เปิดใช้งาน
จุดรับ / จุดหมายค้นหาสถานที่อัตโนมัติขึ้นอยู่กับบริการจำเป็นตามบริการและต้องอยู่ในพื้นที่ให้บริการ
พิกัดระบบขึ้นอยู่กับบริการดึงจากสถานที่ที่เลือก
วันที่ / เวลารับวันที่ / เวลาใช่ตามเวลาจองล่วงหน้าและเวลาทำการ
จำนวนผู้โดยสารจำนวนเต็มใช่มากกว่า 0
จำนวนสัมภาระจำนวนเต็มไม่ตั้งแต่ 0 ขึ้นไป
ระยะเวลา / เที่ยวกลับจำนวนเต็ม / วันและเวลาขึ้นอยู่กับบริการจำเป็นสำหรับบริการที่เกี่ยวข้อง
จุดแวะเพิ่มรายการได้ไม่ทุกจุดแวะต้องอยู่ในพื้นที่ให้บริการ
คำขอพิเศษช่องกรอกข้อความไม่ไม่เกิน 500 ตัวอักษร

ประเภทบริการจะกำหนดข้อมูลที่ต้องกรอก ปุ่มดำเนินการต่อจะบันทึกฉบับร่างและไปยังขั้นตอนเลือกรถ

CUS-006 — การเลือกรถ

แสดงสรุปการเดินทาง ประเภทรถที่รองรับ จำนวนที่นั่ง คุณสมบัติ และราคาโดยประมาณ ลูกค้าเลือกประเภทรถ ไม่ได้เลือกรถทะเบียนใดโดยเฉพาะ ทีมปฏิบัติการจะจัดรถจริงให้ และต้องตรวจสอบรถว่างอีกครั้งก่อนยืนยัน

CUS-007 — ข้อมูลลูกค้า

เก็บข้อมูลว่าจองให้ใคร ชื่อผู้จอง อีเมล เบอร์โทร ชื่อผู้โดยสารเมื่อจองแทนผู้อื่น หมายเลขเที่ยวบิน (ถ้ากำหนด) จุดนัดพบ คำแนะนำพิเศษ การยอมรับเงื่อนไขและรับทราบประกาศความเป็นส่วนตัว ความยินยอมรับข่าวสารเป็นตัวเลือกแยกต่างหาก

CUS-008 — ตรวจสอบและยืนยัน

แสดงการเดินทาง ประเภทรถ ข้อมูลลูกค้า รายการราคา เงินมัดจำ ยอดคงเหลือ และเงื่อนไขที่เกี่ยวข้อง ใบเสนอราคาต้องยังไม่หมดอายุ และระบบหลังบ้านต้องคำนวณราคาและตรวจรถว่างใหม่ บันทึกสำเนาราคาและป้องกันการยืนยันซ้ำ

CUS-009 — ชำระเงิน

แสดงรหัสจอง ยอดรวม เงินมัดจำ ยอดคงเหลือ และช่องทางที่เปิดใช้ ตรวจสอบยอดจากระบบหลังบ้าน ยืนยันลายเซ็นข้อความแจ้งผลจากผู้ให้บริการ รองรับสถานะรอดำเนินการ ล้มเหลว หมดอายุ และสำเร็จ พร้อมลองใหม่อย่างปลอดภัย ห้ามจัดเก็บข้อมูลบัตรฉบับเต็ม

CUS-010 — จองสำเร็จ

แสดงรหัสจอง สรุปรายการ สถานะชำระเงิน ขั้นตอนถัดไป และดาวน์โหลดเอกสารยืนยัน แสดงว่าชำระแล้วเมื่อระบบหลังบ้านตรวจสอบสำเร็จเท่านั้น

CUS-011 — ติดตามการจอง

ค้นหาด้วยรหัสจองและอีเมลหรือเบอร์โทรที่ลงทะเบียน จำกัดจำนวนครั้ง ตรวจสอบข้อมูลติดต่อ เปิดเผยข้อมูลส่วนบุคคลเท่าที่จำเป็น และแสดงข้อมูลคนขับตามนโยบายเท่านั้น

CUS-012–016 — บัญชีลูกค้า

เข้าสู่ระบบ สมัครสมาชิก และรีเซ็ตรหัสผ่านอย่างปลอดภัย แดชบอร์ด ประวัติการจองพร้อมตัวกรองและแบ่งหน้า รายละเอียดการจองพร้อมการดำเนินการที่ได้รับอนุญาต และแก้ไขข้อมูลส่วนตัวโดยยืนยันช่องทางติดต่ออีกครั้ง

CUS-017 — สอบถามบริการองค์กร

เก็บชื่อบริษัท เลขประจำตัวผู้เสียภาษี (ไม่บังคับ) ผู้ติดต่อ อีเมลธุรกิจ เบอร์โทร ความต้องการใช้บริการ ปริมาณโดยประมาณ งบประมาณ (ไม่บังคับ) และรายละเอียด สร้างเลขอ้างอิงคำถามและแจ้งฝ่ายขายหรือผู้ดูแล

CUS-018–020 — การช่วยเหลือและข้อกฎหมาย

ช่องทางติดต่อและคำถามที่พบบ่อย เงื่อนไขการใช้บริการที่ระบุเวอร์ชันและวันที่มีผล ประกาศความเป็นส่วนตัวที่อธิบายวัตถุประสงค์ การเปิดเผย ระยะเวลาเก็บรักษา สิทธิ คุกกี้ และช่องทางติดต่อ

11. ข้อมูลที่แนะนำให้จัดเก็บ

ข้อมูลลูกค้า ที่อยู่ ประเภทบริการ พื้นที่ให้บริการ ประเภทรถ รถ รายการจอง จุดแวะ การจัดรถ สำเนาราคา ประวัติสถานะ ใบเสนอราคา การชำระเงิน การคืนเงิน ความยินยอม คำถามจากองค์กร รีวิว การแจ้งเตือน และประวัติการตรวจสอบ

12. ขอบเขต API ที่เสนอ

วิธีเรียกที่อยู่ APIวัตถุประสงค์
GET/api/v1/servicesแสดงบริการที่เปิดใช้งาน
GET/api/v1/vehicle-categoriesแสดงประเภทรถ
POST/api/v1/availability/searchค้นหารถว่างที่รองรับ
POST/api/v1/quotationsสร้างใบเสนอราคา
POST/api/v1/bookingsสร้างรายการจอง
POST/api/v1/bookings/{reference}/confirmยืนยันรายการจอง
POST/api/v1/payments/intentsสร้างรายการชำระเงิน
GET/api/v1/payments/{id}ดึงสถานะชำระเงิน
POST/api/v1/bookings/trackติดตามการจองของผู้ใช้ทั่วไปอย่างปลอดภัย
POST/api/v1/corporate-inquiriesส่งคำถามจากองค์กร

ที่อยู่ API เหล่านี้เป็นข้อเสนอ ควรกำหนดรูปแบบข้อมูล การยืนยันตัวตน รูปแบบข้อผิดพลาด การป้องกันรายการซ้ำ และการจำกัดจำนวนเรียกก่อนพัฒนา

14. เรื่องที่ต้องสรุปก่อนเปิดใช้งานจริง

  1. ระยะเวลาจองล่วงหน้าขั้นต่ำของแต่ละบริการ
  2. เวลาทำการและวันที่งดให้บริการ
  3. พื้นที่ให้บริการและนิยามเส้นทางหรือโซน
  4. จำนวนที่นั่งจริงของรถแต่ละประเภทและจำนวนรถในคลัง
  5. ราคา ค่าล่วงเวลา ค่ารอ ค่าทางด่วน และค่าจอดรถ
  6. เปอร์เซ็นต์เงินมัดจำและกำหนดเวลาชำระ
  7. นโยบายยกเลิกและคืนเงิน
  8. การติดตามเที่ยวบินและกฎเวลารอที่สนามบิน
  9. วิธียืนยันตัวตนผู้ใช้ทั่วไป
  10. ช่องทางและรูปแบบข้อความแจ้งเตือน
  11. ผู้รับผิดชอบเนื้อหาภาษาไทยและอังกฤษ
  12. ตรวจสอบข้อกฎหมายเกี่ยวกับบริการรถพร้อมคนขับ ใบอนุญาต ประกันภัย และ PDPA
